# Korean Series Recommender

[See the page here!](https://huggingface.co/spaces/Chenjelly/Korean-Series-Recommender)

## Overview

A content-based movie recommendation system built on a curated Korean films dataset. It analyzes genres, keywords, and user preferences to suggest best fitting series according to user input. Designed for K-series fans, this project combines data science, natural language processing, and machine learning to deliver personalized recommendations.

## Functions

- Analyse the user's text input and get desired number of recommendations
- Comput Similarity with movies in the dataset
- Recommend desired number of movies

## Tech Stack

- Python ( Pandas, Pickle )
- Sentence transformers
- PyTorch
- HuggingFace Space
